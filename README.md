# Smart Campus Energy Analytics & Anomaly Detection

## 📌 Project Overview

A smart energy monitoring and analytics system designed to analyze
campus electricity consumption using IoT, Python, Machine Learning
and Power BI.

The system identifies energy consumption patterns, detects unusual
energy usage and predicts expected consumption.

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI
- ESP32
- Energy Sensor
- Machine Learning

## 🏗️ System Architecture

Energy Sensor
      ↓
ESP32
      ↓
Data Collection
      ↓
Python / Pandas
      ↓
Data Analytics
      ↓
Machine Learning
      ↓
Anomaly Detection
      ↓
Power BI Dashboard

## 📊 Features

- Campus energy monitoring
- Zone-wise consumption analysis
- Daily and hourly analysis
- Electricity cost estimation
- Anomaly detection
- Energy consumption prediction
- Power BI dashboard
- Real-time monitoring architecture

## 🤖 Machine Learning

### Anomaly Detection
Isolation Forest

### Energy Prediction
Random Forest Regression

## 📈 Dashboard

The dashboard provides:

- Total energy consumption
- Estimated electricity cost
- Peak load
- Zone-wise consumption
- Hourly consumption
- Anomaly monitoring
- Expected energy consumption
